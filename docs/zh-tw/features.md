# 核心功能

ADEval 具備多項功能，旨在讓評估 ADK Agent 變得高效且可靠。

## 1. 實驗管理 (Experiment Management)
將你的測試組織為「實驗」。每個實驗可以有自己的配置：
- **Agent URL**：ADK Agent 的端點。
- **User ID**：工作階段的上下文 ID。
- **測試案例**：Q-Tools-A 序列的集合。

## 2. Q-Tools-A 驗證
這是 ADEval 的核心，它會驗證 Agent 回覆的三個關鍵部分：
- **Question (Q)**：輸入的提示詞與 Session 狀態。
- **Tools**：Agent 是否呼叫了預期的工具？
  - **Verify Args (關閉)**：僅偵測工具名稱是否存在於實際執行流程中。
  - **Verify Args (開啟)**：進行「智慧比對」，同時驗證工具名稱與參數（支援參數順序無感化的比對）。
- **Answer (A)**：最終回覆是否包含特定的關鍵字？

## 3. 視覺化 Trace (追蹤)
除錯 Agent 的事件流通常很困難。ADEval 提供深色終端機風格的檢視：
- 檢查原始 JSON 事件。
- 追蹤工具執行的時間點。
- 辨識流程在何處發生偏差。

## 4. 批次評估 (Batch Evaluation)
透過 CSV 匯入數十或數百個測試案例。
- **匯入**：輕鬆載入大量測試案例。
- **匯出**：產生測試報告或備份你的題庫。
- **進度監控**：為長時間執行的批次測試提供即時進度條。

## 5. 跨模型比較 (Benchmark)

在 BENCHMARK 分頁把多個實驗疊在同一張雷達圖上比較。

- **矩陣式挑選**：以「模型 × 測資」的格狀介面選取。點格子選單一實驗、點模型名選該模型的所有測資（看難度梯度）、點測資名選所有模型（跨模型比較）。攤平成一排標籤時，數十個實驗會難以操作。
- **聚焦單一指標**：點雷達圖的軸標籤或指標表的任一列，右側換成該指標的排名，並標出最佳值。沒有這項指標的實驗會排除而非以 0 計，面板底部會列出被略過的是哪些。
- **匯出獨立 HTML**：把目前的比較結果存成單一 HTML 檔。**不依賴這個服務**，也沒有任何外部資源，可離線開啟或直接轉寄。匯出的檔案保有矩陣挑選與指標聚焦，收到的人能自行調整要比較哪幾個實驗；列印時會自動轉為白底並隱藏操作介面。

## 6. UI 自定義
- **深色/淺色模式**：隨時切換視覺主題。
- **響應式設計**：在桌機與平板電腦上皆能完美運作。

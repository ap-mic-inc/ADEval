# 核心功能

ADEval 具備多項功能，旨在讓評估 ADK Agent 變得高效且可靠。

## 1. 實驗管理 (Experiment Management)
將你的測試組織為「實驗」。每個實驗可以有自己的配置：
- **Agent URL**：ADK Agent 的端點。
- **User ID**：工作階段的上下文 ID。
- **測試案例**：Q-Tools-A 序列的集合。

## 2. Q-Tools-A 驗證
這是 ADEval 的核心，它會驗證 Agent 回覆的三個關鍵部分：
- **Question (Q)**：輸入的提示詞與 Session 狀態。
- **Tools**：Agent 是否呼叫了預期的工具？
  - **Verify Args (關閉)**：僅偵測工具名稱是否存在於實際執行流程中。
  - **Verify Args (開啟)**：進行「智慧比對」，同時驗證工具名稱與參數（支援參數順序無感化的比對）。
- **Answer (A)**：最終回覆是否包含特定的關鍵字？

## 3. 視覺化 Trace (追蹤)
除錯 Agent 的事件流通常很困難。ADEval 提供深色終端機風格的檢視：
- 檢查原始 JSON 事件。
- 追蹤工具執行的時間點。
- 辨識流程在何處發生偏差。

## 4. 批次評估 (Batch Evaluation)
透過 CSV 匯入數十或數百個測試案例。
- **匯入**：輕鬆載入大量測試案例。
- **匯出**：產生測試報告或備份你的題庫。
- **進度監控**：為長時間執行的批次測試提供即時進度條。

## 5. UI 自定義
- **深色/淺色模式**：隨時切換視覺主題。
- **響應式設計**：在桌機與平板電腦上皆能完美運作。

## 概覽

ADEval 提供直觀的 **Web UI** 與強大的 **CLI** (v0.2.0 新增)，讓你能夠系統化地測試 Agent 的 **Q-Tools-A (Question -> Tools -> Answer)** 流程。它透過以下功能橋接開發與評估：

- **雙模式支持**：可選用視覺化追蹤 (UI) 或自動化執行 (CLI)。
- **系統化測試**：針對預定義的場景測試你的 Agent。
- **實驗追蹤**：保留所有評估的歷史紀錄。
- **視覺化洞察**：透過視覺化的 Trace 功能，精確掌握 Agent 的內部運作。

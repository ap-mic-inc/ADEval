## 概覽

ADEval 提供了一個直觀的 Web UI，讓你能夠系統化地測試 Agent 的 **Q-Tools-A (Question -> Tools -> Answer)** 流程。它透過以下功能橋接開發與評估：

- **系統化測試**：針對預定義的場景測試你的 Agent。
- **實驗追蹤**：保留所有評估的歷史紀錄。
- **視覺化洞察**：透過視覺化的 Trace 功能，精確掌握 Agent 的內部運作。

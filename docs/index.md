## Overview

ADEval provides an intuitive **Web UI** and a powerful **CLI** (introduced in v0.2.0) that allow you to systematically test your Agent's **Q-Tools-A (Question -> Tools -> Answer)** flow. It bridges the gap between development and evaluation by providing:

- **Dual Mode Support**: Choose between visual tracing (UI) or automated execution (CLI).
- **Systematic Testing**: Test your agent against predefined scenarios.
- **Experiment Tracking**: Keep a history of your evaluations.
- **Visual Insights**: See exactly what's happening under the hood with visual tracing.

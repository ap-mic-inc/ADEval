## Overview

ADEval provides an intuitive Web UI that allows you to systematically test your Agent's **Q-Tools-A (Question -> Tools -> Answer)** flow. It bridges the gap between development and evaluation by providing:

- **Systematic Testing**: Test your agent against predefined scenarios.
- **Experiment Tracking**: Keep a history of your evaluations.
- **Visual Insights**: See exactly what's happening under the hood with visual tracing.
